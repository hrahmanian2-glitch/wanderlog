# Thème : histoire(s)

Le mot « histoire » est traité à double sens :

- Récit : chaque utilisateur raconte l'histoire de ses voyages (texte, photos, lieu, date).
- Histoire personnelle: l'ensemble des voyages d'un utilisateur constitue son histoire de vie, visible sur sa page profil et géolocalisée sur la carte.
